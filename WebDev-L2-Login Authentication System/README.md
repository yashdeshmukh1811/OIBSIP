# 🔐 Login Authentication System

A full-stack **Login Authentication System** developed as part of the **Oasis Infobyte (OIBSIP) Web Development Internship – Level 2**.

This project demonstrates how a web application can handle user registration, login, authentication, and database-backed user management using a frontend interface, Node.js backend, and SQLite database.

## 📌 Project Overview

The Login Authentication System provides a basic authentication workflow where users can interact with a web interface and securely manage their login credentials.

The project combines frontend technologies with a backend server and database to demonstrate the fundamentals of full-stack web development and authentication.

## ✨ Features

* 🔐 User authentication
* 📝 User registration
* 👤 User login
* 🗄️ SQLite database integration
* 🌐 Backend server using Node.js
* 🖥️ Frontend authentication interface

* 📦 Node.js package management
* 🛡️ Authentication-focused application structure
* 📱 User-friendly web interface

## 🛠️ Technologies Used

* **HTML5** — Frontend page structure

* **JavaScript** — Client-side functionality
* **Node.js** — Backend runtime environment
* **SQLite** — Database for storing application data

## 📂 Project Structure

```text
WebDev-L2-Login Authentication System/
│
├── public/
│   └── [frontend files]
│
├── database.sqlite
├── package.json
├── package-lock.json
├── server.js
└── README.md
```

### `public/`

Contains the frontend files used by the application, including the user interface and client-side resources.

### `server.js`

Contains the backend server logic responsible for handling application requests and authentication-related functionality.

### `database.sqlite`

SQLite database file used for persistent application data.

### `package.json`

Contains project metadata, scripts, and Node.js dependencies.

### `package-lock.json`

Locks the installed dependency versions to provide consistent installations.

## 🚀 Getting Started

### Prerequisites

Make sure you have **Node.js and npm** installed on your system.

### 1. Clone the repository

```bash
git clone https://github.com/yashdeshmukh1811/OIBSIP.git
```

### 2. Navigate to the project directory

```bash
cd OIBSIP/WebDev-L2-Login\ Authentication\ System
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the server

```bash
node server.js
```

### 5. Open the application

Open the local address provided by the server in your web browser.

## 🔑 Authentication Workflow

The application follows a basic authentication flow:

```text
User
  │
  ▼
Frontend Login / Registration
  │
  ▼
Node.js Server
  │
  ▼
Authentication Logic
  │
  ▼
SQLite Database
  │
  ▼
Authentication Response
  │
  ▼
User Interface
```

## 🗄️ Database

The project uses **SQLite** for database management.

The database provides persistent storage for authentication-related application data and allows the backend to retrieve and manage user information.

## ⚠️ Security Note

This project is intended as an **educational internship project** demonstrating authentication concepts.

For production applications, authentication systems should use appropriate security practices such as password hashing, secure session management, input validation, HTTPS, protection against common web vulnerabilities, and secure handling of authentication secrets.
