# 🌐 OIBSIP — Web Development Internship

A collection of web development projects completed as part of the **Oasis Infobyte (OIBSIP) Web Development Internship**.

This repository contains practical projects developed across **Level 1 and Level 2**, covering frontend development, responsive UI design, JavaScript programming, and full-stack web development.

## 📌 About the Repository

The purpose of this repository is to document my learning journey and practical experience during the OIBSIP Web Development Internship.

Each project focuses on a different aspect of web development, starting with fundamental HTML/CSS projects and progressing toward interactive JavaScript applications and a full-stack authentication system.
