# ✅ To-Do Web App

A simple, interactive, and user-friendly **To-Do Web Application** developed as part of the **Oasis Infobyte (OIBSIP) Web Development Internship – Level 2**.

This project allows users to create and manage their daily tasks through a clean and responsive web interface.

## 📌 Project Overview

The To-Do Web App is designed to help users organize their tasks and keep track of their daily activities.

The application demonstrates practical use of **HTML5, CSS3, and JavaScript** to create an interactive frontend web application with dynamic task management.

## ✨ Features

* ✅ Add new tasks
* 📝 Manage daily tasks
* ✔️ Mark tasks as completed
* 🗑️ Remove tasks
* ⚡ Dynamic task updates
* 🎨 Clean and user-friendly interface
* 📱 Responsive design
* 💻 Runs directly in a web browser
* 🔄 Interactive task management

## 🛠️ Technologies Used

* **HTML5** — Used to structure the application
* **CSS3** — Used for layout, styling, and responsive design
* **JavaScript** — Used to implement task management and user interactions

## 📂 Project Structure

```text
WebDev-L2-To Do Web App/
│
├── index.html
├── style.css
├── app.js
└── README.md
```

### `index.html`

Contains the structure of the To-Do application, including the input area, task section, and user interface elements.

### `style.css`

Contains the styling, layout, typography, spacing, colors, and responsive design of the application.

### `app.js`

Contains the JavaScript functionality responsible for adding, updating, completing, and managing tasks.

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/yashdeshmukh1811/OIBSIP.git
```

### 2. Navigate to the project directory

```bash
cd OIBSIP/WebDev-L2-To\ Do\ Web\ App
```

### 3. Open the application

Open `index.html` in any modern web browser.

No additional installation or dependencies are required.
