# 💼 Personal Portfolio Website

A modern and responsive **Personal Portfolio Website** developed as part of the **Oasis Infobyte (OIBSIP) Web Development Internship – Level 1**.

The portfolio showcases personal information, skills, projects, and professional interests through a clean and user-friendly web interface.

## 📌 Project Overview

This project was created to demonstrate fundamental front-end web development skills by building a personal portfolio from scratch using **HTML5 and CSS3**.

The website provides an online space to introduce myself, highlight my technical skills, showcase projects, and provide a way for visitors to connect with me.

## ✨ Features

* 👨‍💻 Personal introduction
* 📝 About Me section
* 🛠️ Skills and technologies section
* 🚀 Projects showcase
* 📄 Professional information
* 📬 Contact section
* 📱 Responsive and user-friendly design
* 🎨 Custom CSS styling
* ⚡ Lightweight and fast-loading webpage

## 🛠️ Technologies Used

* **HTML5** — Used to create the structure and content of the portfolio
* **CSS3** — Used for styling, layout, responsiveness, and visual design
