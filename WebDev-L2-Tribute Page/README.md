# 🧮 Calculator Web Application

A simple, interactive, and user-friendly **Calculator Web Application** developed as part of the **Oasis Infobyte (OIBSIP) Web Development Internship – Level 2**.

This project demonstrates the use of **HTML, CSS, and JavaScript** to build a functional calculator capable of performing common arithmetic operations.

## 📌 Project Overview

The Calculator is a browser-based web application designed to perform basic mathematical calculations through an easy-to-use interface.

The project focuses on creating a clean calculator layout, handling user input, implementing calculation logic with JavaScript, and displaying results dynamically.

## ✨ Features

* 🧮 Basic arithmetic calculations
* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🔢 Number input through calculator buttons
* 🧹 Clear/reset functionality
* ⚡ Instant calculation results
* 🎨 Clean and simple user interface
* 📱 Responsive design
* 🌐 Runs directly in a web browser

## 🛠️ Technologies Used

* **HTML5** — Creates the structure of the calculator
* **CSS3** — Handles layout, styling, buttons, and responsive design
* **JavaScript** — Implements calculator functionality and arithmetic operations

## 📂 Project Structure

```text
WebDev-L2-Calculator/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

### `index.html`

Contains the structure of the calculator interface, including the display and calculator buttons.

### `style.css`

Provides the visual design, layout, spacing, typography, and responsive styling.

### `script.js`

Contains the calculator's functionality and JavaScript logic for processing user input and performing calculations.
