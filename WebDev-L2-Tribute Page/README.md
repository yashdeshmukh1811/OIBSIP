# 🌟 Tribute Page

A responsive and visually appealing **Tribute Page** developed as part of the **Oasis Infobyte (OIBSIP) Web Development Internship – Level 2**.

This project presents a dedicated tribute to an inspiring personality, combining meaningful content with an attractive and user-friendly web design.

## 📌 Project Overview

The Tribute Page is designed to highlight the life, achievements, contributions, and memorable aspects of a respected personality.

The project demonstrates the use of **HTML5, CSS3, and JavaScript** to create a structured, interactive, and visually engaging webpage.

## ✨ Features

* 🌟 Dedicated tribute section
* 👤 Personality introduction
* 📖 Informative content about their life and achievements
* 🖼️ Image section
* 🎨 Clean and attractive user interface
* 📱 Responsive webpage design
* ⚡ JavaScript-based interactions
* 🧭 Well-organized page structure
* 💻 Compatible with modern web browsers

## 🛠️ Technologies Used

* **HTML5** — Used to structure the webpage and organize the tribute content
* **CSS3** — Used for styling, layout, typography, animations, and responsive design
* **JavaScript** — Used to add interactivity and dynamic behavior

## 📂 Project Structure

```text
WebDev-L2-Tribute Page/
│
├── image/
│   └── [tribute page images]
│
├── index.html
├── script.js
├── style.css
└── README.md
```

### `index.html`

Contains the main structure and content of the tribute page.

### `style.css`

Contains the visual styling, page layout, typography, spacing, responsiveness, and overall design.

### `script.js`

Contains the JavaScript functionality used to add interactive behavior to the webpage.

### `image/`

Contains the images used throughout the tribute page.

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/yashdeshmukh1811/OIBSIP.git
```

### 2. Navigate to the project directory

```bash
cd OIBSIP/WebDev-L2-Tribute\ Page
```

### 3. Open the website

Open `index.html` in any modern web browser.

No additional libraries, frameworks, or dependencies are required.
