# 🌐 Landing Page — OIBSIP Web Development Internship

A responsive and visually appealing **Landing Page** developed as part of the **Oasis Infobyte (OIBSIP) Web Development Internship – Level 1, Task 1**.

The project demonstrates the use of **HTML5 and CSS3** to create a structured, attractive, and user-friendly web page.

## 📌 Project Overview

This landing page was created to practice fundamental web development concepts such as:

* Structuring web pages using HTML
* Styling and designing interfaces using CSS
* Creating attractive layouts and sections
* Using modern CSS techniques
* Building a responsive and user-friendly interface

## 🛠️ Technologies Used

* **HTML5** — Page structure and content
* **CSS3** — Styling, layout, and visual design

## 📂 Project Structure

```text
WebDev-L1-LandingPage/
│
├── index.html
├── style.css
└── README.md
```

### Files

**`index.html`**
Contains the structure and content of the landing page.

**`style.css`**
Contains the styling, layout, typography, spacing, and visual appearance of the website.

## ✨ Features

* Clean and modern landing page design
* Well-structured HTML layout
* Custom CSS styling
* User-friendly interface
* Responsive layout
* Organized project structure
* Suitable for desktop and mobile screen sizes

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/yashdeshmukh1811/OIBSIP.git
```

2. Navigate to the project directory:

```bash
cd OIBSIP/WebDev-L1-LandingPage
```

3. Open `index.html` in your preferred web browser.

No additional dependencies or installation are required.
