# 🌡️ Temperature Converter Website

A simple, interactive, and user-friendly **Temperature Converter Website** developed as part of the **Oasis Infobyte (OIBSIP) Web Development Internship – Level 1**.

The project allows users to convert temperature values between different temperature units through a clean and responsive web interface.

## 📌 Project Overview

This project demonstrates fundamental front-end web development concepts by creating a functional temperature conversion tool using **HTML, CSS, and JavaScript**.

Users can enter a temperature value, select the desired conversion units, and instantly view the converted temperature.

## ✨ Features

* 🌡️ Convert temperature values easily
* 🔄 Support for multiple temperature units
* ⚡ Instant conversion using JavaScript
* 🎨 Clean and simple user interface
* 📱 Responsive design
* 🖱️ Easy-to-use controls
* 🚫 Input validation for better user experience
* 💻 Works directly in a web browser

## 🔢 Temperature Conversion

The converter can be implemented using standard temperature conversion formulas such as:

### Celsius to Fahrenheit

```text
°F = (°C × 9/5) + 32
```

### Fahrenheit to Celsius

```text
°C = (°F − 32) × 5/9
```

### Celsius to Kelvin

```text
K = °C + 273.15
```

### Kelvin to Celsius

```text
°C = K − 273.15
```
